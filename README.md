# <模组名> / Ore Biome Reforged

> 一个受 **矿石生态群系（Ore Biome）** 启发，为 **Forge 1.20.1** 重新设计的矿石生态群系模组。  
> A Forge 1.20.1 mod inspired by Ore Biome, rebuilt with a modern config GUI and ore scanning.

## 简介

你是否想过，如果 Minecraft 的生态群系直接由矿石构成，挖矿会变成怎样一种体验？

本模组在保留“矿石群系”核心玩法的基础上，针对 Forge 1.20.1 进行了现代化重构。原版模组长期停留在 1.12.2，配置依赖手动编辑 `.cfg` 文件，添加模组矿石时格式繁琐、容易出错。本模组重新设计了配置交互方式，让矿石群系的管理变得直观、可控、开箱即用。

---

## 功能特性

### 🎛️ 可视化配置 GUI，快捷开关矿石生成

内置完整的游戏内配置界面。可以在 Mods 配置菜单中直接打开，以列表形式查看所有已启用的矿石。每种矿石旁都配有开关按钮，一键决定它是否会在矿石生态群系中生成。

不再需要记忆 `模组名:矿石名:元数据` 的格式，也不再需要反复重启游戏测试配置是否生效。

### 🔍 一键扫描整合包矿石，自由选择添加

整合包里装了大量模组，每个模组都带了自己的矿石，想全部加进矿石群系怎么办？

本模组提供一键扫描功能。点击扫描后，模组会自动遍历当前游戏环境中所有已注册的矿石方块，包括原版矿石和各个模组添加的矿石，并将它们整理成一份可选择的列表。你只需要在列表中勾选想要加入矿石生态群系的矿石，保存即可生效。

锡、银、铅、铂、铱……无论整合包里有什么，它都能识别并纳入管理。

### ⚙️ 生态群系稀疏度三档调节

矿石生态群系里的矿石密度，直接决定了这个群系是“矿工的应许之地”还是“可持续挖矿示范区”。

本模组提供三档预设模式：

| 模式 | 说明 |
| --- | --- |
| **稀疏** | 矿石群系生成概率和内部矿石密度较低，适合正常生存节奏。 |
| **适中** | 默认平衡档位，既有惊喜感，又不至于破坏游戏平衡。 |
| **稠密** | 矿石群系生成更频繁，内部矿石更密集，适合追求挖矿爽感或快速获取资源。 |

切换档位即时生效，只需在 GUI 中选择对应模式即可。

## 使用说明

### 打开配置界面

创建世界时页面左上角会有配置按钮，进入游戏后，打开 **Mods** 列表，找到本模组，点击 **Config** 按钮即可进入配置 GUI，也可在暂停页面左上角配置按钮处进入。

### 扫描并添加矿石

1. 在配置界面中点击 **扫描矿石**。
2. 等待扫描完成，列表会显示当前环境中所有已注册的矿石方块。
3. 勾选你希望加入矿石生态群系的矿石。
4. 保存配置并重启游戏或重新加载世界。

### 调整稀疏度

在配置界面中找到 **生成密度** 选项，从下拉菜单中选择 **稀疏 / 适中 / 稠密**，保存即可。

## 注意事项

- **世界生成**：矿石生态群系的生成规则在创建新世界或生成新区块时生效，已生成的区块不会自动追加新的矿石群系。
- **扫描范围**：扫描功能依赖于模组正确注册的矿石方块，优先读取 `forge:ores` 标签。如果某个模组的矿石未正确注册，可能无法被自动识别。
- **性能**：稠密模式下矿石群系内的连锁挖矿可能产生大量掉落物和粒子效果，建议根据设备性能酌情选择。
- **备份**：修改世界生成相关配置前，建议备份存档。
